# Build Wave 5 Batch 2 — Technical Content Blocks and Lightweight Organization

**Date:** 2026-08-12

## Scope

Implements the MVP foundation for:

- KNOW-002 — Technical Content Blocks
- KNOW-004 — Tags and Lightweight Organization

## Delivered

Technical note blocks for paragraph, heading, bulleted list, numbered list,
checklist, code, command, terminal/output, quote, callout, link, and simple table.

Also delivered:

- stable block IDs;
- deterministic ordering;
- optional language labels;
- inert command/code/output storage;
- student-owned RLS;
- create/rename/delete tags;
- multiple tags per note;
- pinned state;
- tag sanitization;
- authenticated route protection.

Commands, code, and terminal output are data only and never execute.

## Deferred

Browser editor polish, private note search/filter UX, bookmarks, export, and AI
assistance remain in later Wave 5 batches.
